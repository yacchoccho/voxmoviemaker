# VoxMovieMaker

VoxMovieMakerは、VOICEVOXの音声生成に対応したLinux向け動画編集ソフトです。動画や画像にナレーションと字幕を組み合わせ、MP4・WebMとして書き出せます。

現在は開発版です。対応機能や既知の問題は[開発状況](docs/STATUS.md)を参照してください。

## 主な機能

- 動画・画像・音声を、ファイルマネージャーからタイムラインへ直接追加
- クリップの移動・分割・トリミング、コピー＆ペースト、Undo / Redo
- VOICEVOXによる音声生成と字幕の自動配置。音声と字幕を一つのクリップとして編集
- 字幕・タイトルの追加、プレビュー上での移動・拡大縮小
- 音量・不透明度・フェード・トランジションの調整
- 音声付きプレビュー、MP4 / WebMへの書き出し
- 日本語・英語・簡体字中国語、Dark・Light・Systemテーマ

## 動作環境

| 項目 | 必要なもの |
| --- | --- |
| OS | Linux x86_64（Wayland / X11） |
| 画面表示 | OpenGL/EGL、xkbcommon、日本語対応フォント |
| メディア処理 | FFmpeg・ffprobe |
| 音声生成 | VOICEVOX ENGINE（音声生成を使う場合） |
| プレビューの音声 | システムALSA（`libasound.so.2`） |
| VOICEVOXの試聴 | `pw-play` または `aplay` |

**FFmpeg・ffprobe・VOICEVOXは別途導入が必要です。** VoxMovieMakerには同梱せず、自動ダウンロード・インストールやVOICEVOX ENGINEの起動・停止も行いません。

## インストールと起動

現在はソースコードからビルドして利用します。一般向けインストーラー・AppImageは未提供です。

### 1. 外部ソフトを準備

FFmpeg・ffprobeを導入します。Ubuntu / Debian系では次のコマンドを使用できます。

```bash
sudo apt install ffmpeg
```

その他の環境は[FFmpegの配布案内](https://ffmpeg.org/download.html)を参照してください。

音声生成を使う場合は、[VOICEVOX ENGINEの導入案内](https://github.com/VOICEVOX/voicevox_engine)に従ってENGINEを導入・起動してください。

### 2. ビルドして起動

Rust Stable 1.88以上とLinuxの開発用ツール・リンカーを用意し、`Cargo.toml` のあるディレクトリで実行します。

```bash
cargo build --locked --release --bin voxmoviemaker
./target/release/voxmoviemaker
```

ビルド済みの実行ファイルを使用する場合は `./voxmoviemaker` で起動します。

### 3. 接続を確認

「設定」でFFmpeg・ffprobeのパスを確認し、「バージョン・エンコーダーを検出」を押します。VOICEVOXの接続先は、初期状態では `http://127.0.0.1:50021` です。

## 使い方

### 素材を並べて編集する

動画・画像・音声をタイムラインへドラッグ＆ドロップするか、「＋素材」からファイルを選択します。横方向が開始時刻、縦方向がレイヤーです。

どのレイヤーにも異なる種類の素材を配置できます。**下のレイヤーほど映像の前面に表示されます。** 透明画像を重ねても背面の映像が見え、音声はレイヤー順に関係なくミックスされます。

| 操作 | 方法 |
| --- | --- |
| 移動 | タイムラインでクリップをドラッグ |
| 分割・削除 | クリップを右クリック |
| トリミング・長さ・音量 | 右側のプロパティで調整 |
| 映像・文字の位置 | プレビューでドラッグ |
| 映像・文字の大きさ | プレビュー上でホイール操作 |
| レイヤーの追加・並べ替え | タイムラインの操作ボタン |
| 言語・テーマ | 「表示」メニュー |

同一レイヤー内ではクリップを重ねられません。素材追加や音声生成で重なる場合は、下側の空きレイヤーへ自動配置します。

解像度・FPSは編集を始める前に設定してください。時間の入力はフレーム単位です（30 FPSなら30フレーム＝1秒）。

### ナレーションと字幕を追加する

1. ENGINEを起動し、「VOICEVOXへ接続」を押します。
2. 配置するレイヤーと再生ヘッド位置を選びます。
3. 最下部へ文章を入力し、右側で話者・スタイル・読み上げ設定を選びます。
4. **Enterで生成・配置、Shift+Enterで改行**します。「試聴」「生成して配置」ボタンも使えます。

生成した音声には字幕が付き、移動・分割・削除を一つのクリップとして扱えます。字幕の表示・文章・書式は右側で変更できます。

既存の音声を変更する場合は、クリップを選んで「選択クリップを再生成」を押します。通常の生成操作では新しいクリップを追加します。生成済み音声はENGINEを終了した後も利用できます。

独立した字幕やタイトルは「＋字幕」「＋テキスト」から追加します。字幕の初期位置は画面下、テキストは中央です。

### 保存・書き出し

| 目的 | 操作 |
| --- | --- |
| 編集を保存 | 「ファイル」→「保存」。保存ダイアログでフォルダーと名前を選び、確認画面で「決定」 |
| 編集を再開 | 「プロジェクトを開く…」から `.vmm.json` のパスを入力 |
| 素材ごと別PCへ移す | 「アセット付きプロジェクトを書き出す…」。Git管理外の新しいフォルダーを絶対パスで指定 |
| 完成動画を作る | 「動画を書き出す…」→形式を選択→「保存先を選ぶ…」→「決定」 |

プロジェクトファイルには素材そのものを含みません。別PCへ移す場合は、アセット付き書き出しを利用してください。元の動画・音声は変更せずに編集します。

初回保存と「名前を付けて保存…」では保存先を選択できます。`.vmm.json` は自動で付き、既存ファイルを指定した場合は上書き確認が必要です。保存後のCtrl+Sは同じファイルへ保存します。

動画の保存先はフォルダーとファイル名を選択でき、拡張子は形式に合わせて付きます。既存の出力ファイルは上書きしません。ファイル選択には導入済みのZenityを使い、利用できない場合はアプリ内ブラウザーが開きます。

| 動画形式 | 必要なFFmpegエンコーダー |
| --- | --- |
| MP4（H.264 / AAC） | `libx264` / `aac` |
| WebM（VP9 / Opus） | `libvpx-vp9` / `libopus` |

### キーボードショートカット

| キー | 操作 |
| --- | --- |
| Space | 再生・一時停止 |
| ← / → | 1フレーム移動 |
| S / Delete | 選択クリップを分割 / 削除 |
| Ctrl+C / Ctrl+V | コピー / 貼り付け |
| Ctrl+Z / Ctrl+Y | Undo / Redo |
| Ctrl+S / Ctrl+O | プロジェクトを保存 / 開く |
| Esc | プレビューでのドラッグ移動を取り消す |

文字入力中は入力操作を優先します。

## データの保存先

`~` はホームディレクトリです。

| データ | 標準の保存先 |
| --- | --- |
| **生成したVOICEVOX音声（WAV）** | `~/.local/share/voxmoviemaker/projects/<project-uuid>/voice/<audio-uuid>.wav` |
| **キャッシュ** | `~/.cache/voxmoviemaker/` |
| 静止プレビュー | `~/.cache/voxmoviemaker/frames/` |
| 連続再生用プロキシ | `~/.cache/voxmoviemaker/proxies/` |
| 設定 | `~/.config/voxmoviemaker/settings.json` |

**生成音声は永続保存され、キャッシュの整理では削除されません。** 試聴で生成した音声も保存します。

XDG環境変数を絶対パスで設定している場合は、次の場所を使います。未設定・空・相対パスの場合は上の標準パスを使います。

- 音声：`$XDG_DATA_HOME/voxmoviemaker/projects/<project-uuid>/voice/<audio-uuid>.wav`
- キャッシュ：`$XDG_CACHE_HOME/voxmoviemaker/`
- 設定：`$XDG_CONFIG_HOME/voxmoviemaker/settings.json`

音声の保存先は「設定」でも変更できます。既存音声は自動移動しません。Git管理下への音声保存や、音声とキャッシュが重なる保存先は使用できません。

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 素材を読み込めない・動画を書き出せない | FFmpeg・ffprobeの検出結果、エンコーダー、保存先の権限・空き容量 |
| VOICEVOXに接続できない | ENGINEの起動状態、接続先URL |
| 音が出ない | クリップ・レイヤーのミュート、音量、ALSAデバイス。試聴の場合は `pw-play` / `aplay` |
| 素材が見つからない | 右側の「欠損素材を再リンク…」から素材を選択し直す |
| プレビューの準備が長い | 初回や編集後は再生用プロキシを生成します。プレビュー幅と空き容量を確認 |

現在、クリップ端のドラッグによるトリミング、SRT/ASS入出力、キーフレーム、音量リミッター、不要な生成音声の一括整理には対応していません。プロジェクトの読み込みとアセット付き書き出し先はパス入力です。長時間編集や低スペックPCでの性能には追加検証が必要です。
