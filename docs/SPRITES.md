# PSD立ち絵

## 使い方

1. タイムラインまたは「編集」の「立ち絵クリップ設定」を開き、「立ち絵を登録」を押します。
2. 名前を付け、ファイル選択画面からPSDを選びます。基本設定のツリーで初期表示レイヤーを切り替えます。
3. 口パクに使うキャラクターを選びます。同じキャラクターに複数の立ち絵設定を登録できます。
4. 口タブで有効化し、「閉じた口」「開いた口」と無音のしきい値・開閉の待ち時間を設定します。目タブは従来どおり通常時のレイヤーと可変コマ・表示時間・速度を設定します。どちらも複数レイヤーを選択できます。レイヤーのドロップダウンには要素のサムネイルを表示し、画像をクリックしても選択できます。透明部分は市松模様、グループは元の子レイヤーの表示状態を合成して示します。グループを指定すると、初期表示の子レイヤーを合成して使います。非表示の差分を一度に全部表示することはありません。
5. 下部のフレーム位置でシークし、「発話中として確認」のオン・オフで口パクを確認します。目パチは発話と独立して動きます。
6. 「再生ヘッド位置へ立ち絵を配置」で5秒の汎用クリップを配置します。長さ・トリミング・位置・拡大率・透明度は既存のプロパティ、移動・分割・複製・削除は既存のタイムライン操作を使います。

設定の有効な変更は自動保存します。IME変換中と一時的な空の名前は保存しません。保存失敗時は編集用の値を保持し、「保存」で再試行できます。別インスタンスとの競合時は「再読み込み」から最新の設定を読み直してください。

別のPSDを選ぶとレイヤー対応・口パク・目パチを初期化します。PSD自体をアプリから変更・保存する機能はありません。元ファイルの更新でレイヤーが消えた場合は、選択内容を設定し直してください。

## データの分担

| データ | 保存先・扱い |
| --- | --- |
| 全立ち絵の共通定義 | `$XDG_CONFIG_HOME/voxmoviemaker/sprites.json`、未設定・空・相対パスなら `~/.config/voxmoviemaker/sprites.json` |
| PSD本体 | 選択した絶対パスを参照。自動コピー・上書き・削除しない |
| プロジェクト | `ClipSource::Sprite { settings_id: UUID }` と、既存の時間・レイヤー・効果のみ |
| 音声解析キャッシュ | `$XDG_CACHE_HOME/voxmoviemaker/text/speech/`、未設定時 `~/.cache/voxmoviemaker/text/speech/`。削除後はWAVから再生成 |
| デコード済みレイヤー | メモリ内の上限付きLRU。各コマは画像を複製せずレイヤーキーを参照 |
| FFmpegへ渡す画像・連結リスト | `$XDG_CACHE_HOME/voxmoviemaker/text/vmm-sprite-<uuid>/`、未設定時 `~/.cache/voxmoviemaker/text/` 配下。処理後に削除 |

共通ファイルは `schema_version: 1` と立ち絵のUUID・名前・PSDパス・キャラクターUUID・表示上書き・口の開閉レイヤー・無音判定・開閉待ち時間、目のコマ列・通常時レイヤー・速度・目パチ待ち時間（互換性のため旧口コマ列も保持）を保存します。独自の `sprites.lock` による排他、読み取り時の内容との比較、モード0600の一時ファイルからの原子的置換を使用します。破損・未知のバージョン・アクセス拒否時は書き込みを保護します。

共通定義はプロジェクトの保存・Undoの対象外です。新規・読み込み時や設定の「再読み込み」で最新の定義を読み、変更後のプレビュー・プロキシを再生成します。同時起動した別インスタンスでの編集は自動マージしません。

プロジェクト形式はschema 5です。schema 1〜4の既存プロジェクトも読み込めます。立ち絵の詳細、PSDパス、レイヤー画像はプロジェクトJSONへ埋め込みません。アセット付き書き出しもこれらを含めないため、別PCでは `sprites.json` とPSDを別途用意し、パスや参照先を設定してください。キャラクター共通設定も別管理です。

設定・PSDが欠損した場合は読み込みやプロパティ、プレビュー・出力時に通知します。参照ID・クリップは削除せず、設定を復元するかプロパティで別の立ち絵設定を割り当てられます。

## 時間と合成

- 目パチの `AnimationFrame` は可変長のレイヤーキー一覧と整数ミリ秒の長さです。1〜128コマ、1コマ1〜60000ms、速度0.1〜10倍に対応します。
- 口は同じキャラクターIDの有効なVOICEVOX音声のWAVを10msごとのRMSで解析します。クリップ音量・トリミング・移動・ミュートを反映し、同キャラクターの音声が重なる場合はどれか一つが有音なら開きます。別キャラクター、未割り当ての音声、通常の音声素材は駆動しません。
- 通常時のレイヤーが未選択の場合は、PSDの初期表示と基本設定の表示指定を維持します。レイヤー未選択のコマは通常時の表示に戻ります。コマを設定しただけで、無効状態や発話・目パチの待機中に口・目が消えることはありません。
- 有音中は開いた口を保持し、無音中は閉じた口へ戻ります。初期値は−40dBFS、開くまで20ms、閉じるまで80msで、−80〜0dBFS・各0〜2000msに調整できます。旧設定は通常時レイヤーを閉じた口、中央（偶数コマなら後ろ側）のコマを開いた口として読み込み、口の速度・繰り返しは使用しません。
- 目は立ち絵の素材オフセット＋クリップ内フレーム位置から計算し、「待ち時間 → コマ列 → 待ち時間」を繰り返します。待ち時間は速度適用前の100〜600000msです。口を止めても目は継続します。
- 素材オフセットを使うため、立ち絵を分割・トリミングした後も目パチの位相を保持します。移動・コピーでは配置先の同キャラクター音声との重なりを再評価します。
- 有理数FPSと整数演算による絶対位置の評価です。24000/1001・30000/1001でもフレームごとの経過時間を足し合わせず、システム時刻や乱数は使いません。
- 口・目で制御するレイヤー集合だけを切り替え、体・髪・服などは初期表示を維持します。名前が `*` で始まる同階層の差分は選択された部品へ切り替え、元から表示されていた別の口・目が残らないようにします。口と目の制御範囲が交差する設定は、グループの子孫と差分の範囲も含めてエラーにします。
- 選択した部品の祖先グループを表示し、差分グループの初期構成を復元します。例えば目セット内の黒目を指定した場合は白目も復元し、閉じ目へ切り替えた場合は開き目側の目セットを隠します。`*` のない通常レイヤーを無関係な差分として自動的に隠すことはありません。
- PSDの下から上への順番、RGBA、座標、通常レイヤーの不透明度・塗りの不透明度、グループの不透明度を保持します。VMMの汎用レイヤーでは引き続き下段が前面です。

`RenderPlan::with_libraries` が共通設定と音声参照を取得し、ワーカー内で音声判定を解決します。静止プレビュー・連続再生用プロキシ・動画書き出しが同じ設定スナップショットを使います。静止時は対象フレームだけを合成し、連続時は状態が変化する境界だけを列挙して、同じ表示状態のPNGを再利用します。FFmpegのconcat時間精度に合わせて絶対境界の差を使い、NTSCの丸め誤差の累積も防ぎます。

音声解析は既存の `hound` を使い、WAV全体のPCMをメモリへ展開しません。整数PCM／float WAV、1〜8チャンネル、1〜192kHz、1ファイル1時間までを対象とし、解析失敗・欠損・解析中の変更はエラー表示して処理を中断します。音声レベルは最大8ファイル、判定区間は最大8条件をメモリで再利用し、ディスクの解析キャッシュは最大約64MiBに制限します。

ファイルの大きさ・mtime・ctime・inodeでWAVの変更を検出します。しきい値・音量・トリミング変更時は保存した音量から判定をやり直し、各クリップの先頭から評価するためシーク履歴に影響されません。開閉はタイムラインのフレーム境界に丸め、クリップ終端以降には延長しません。音声フェードの音量変化と音素・母音解析は口の判定に含めません。

## 対応範囲と上限

RGB 8bitのPSD/PSB画像レイヤー、ネストしたグループ、通常合成とパススルーグループを対象とします。画像はPhotoshopと同じ色管理を行わず、RGBA値として合成します。初期実装はレイヤーマスク・クリッピング・ベクトル・調整・ライブテキスト・スマートオブジェクト・レイヤー効果・通常以外の描画モード等を拒否します。PSD側で通常の画像レイヤーへラスタライズ・整理してください。

ファイル上限64MiB、キャンバスRGBA上限64MiB、全レイヤーRGBA見積り上限192MiB、レイヤーレコード2048件、ネスト32段です。グループ合成の作業キャンバスも128MiBまでに制限します。パーサーの制限より小さなVMM側の上限を、RGBAのデコード前に検査します。

解析済み文書は最大2件、各文書のデコード済み画像LRUは64MiBまで保持します。参照中の画像はArcで共有します。レイヤー選択用サムネイルは表示範囲だけをバックグラウンドで生成し、64×64以内の画像を最大128件テクスチャとして再利用します。PSD切り替え時はキャッシュと古い要求を破棄し、サムネイル用ファイルはディスクへ保存しません。ファイルの大きさ・mtime・ctime・inodeを確認して元PSDの変更を検出し、古い設定スナップショットと異なるPSDで出力しようとした場合は中断します。再生中の外部変更を監視する仕組みはないため、変更後は「更新」または再読み込みしてください。

1回の描画準備は最大1024表示状態・250000区間・PNG合計256MiBです。範囲を超える場合は明示的なエラーにし、動画全体のRGBAフレームをRAMへ展開しません。通常終了・失敗・キャンセルで一時ファイルを破棄しますが、異常終了後の残存一時フォルダーの自動整理は未実装です。

設定画面はフレーム位置を指定するシークプレビューです。設定画面内の自動連続再生、音素解析、立ち絵設定の持ち出し・自動同期、さらに多くの配布立ち絵での互換性評価は今後の課題です。4GB PCでの実測と実IME・OSダイアログの手動評価も未実施です。

## 外部PSDによる検証

ローカルに用意されたPSDTool対応の立ち絵（1082×1650、127レイヤーレコード）で、口の差分置換、目セット・白目・黒目・閉じ目、体や服装の維持、全要素のサムネイルを検証しました。口パク・目パチを含む36フレームについて、実FFmpegで静止プレビュー・再生用プロキシ・MP4を比較しています。PSDの読み取り前後のバイト列も一致しました。

PSDとそこから作成した画像・動画はリポジトリへ収録しません。PSD/PSBの誤追加は `.gitignore` でも防ぎます。テストコードは `VMM_TEST_PSD` でリポジトリ外の素材を明示指定したときだけ実行でき、通常の `cargo test` は独自の単色PSDを使います。

```bash
VMM_TEST_PSD=/absolute/path/to/local-artwork.psd cargo test --locked --test psd_external -- --ignored
```

この外部テストは、同素材の `!口`・`!目`・`*目セット` 等の構造を対象にします。PSDを変えた場合は構造に合わせたテストが必要で、全PSD・PSDToolの機能すべての互換性を保証するものではありません。`examples/inspect-psd.rs` は読み取り専用の汎用診断ツールで、`--render` 指定時の派生画像も新しい一時ディレクトリにだけ保存します。
