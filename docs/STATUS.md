# VoxMovieMaker 開発・検証状況

最終動作検証日は2026-11-08です。Phase 0〜5の主要機能を実装した開発版で、配布前の最終確認は完了していません。

## 実装済み機能

- **画面・設定（Phase 0）**：Rust製GUI、Wayland/X11、日本語・英語・簡体字中国語、テーマ切替に対応しています。右側にプロパティ、最下部にVOICEVOX入力欄を配置しています。

- **タイムライン編集（Phase 1）**：素材の直接ドロップ、移動・分割・数値トリミング・削除・コピー、Undo/Redo、レイヤーの並べ替えに対応しています。すべて汎用レイヤーで、下段ほど映像の前面になります。

- **VOICEVOX（Phase 2）**：入力欄の上でキャラクターを検索・選択し、共通の話者・音声・字幕設定で生成できます。生成WAVはGit管理外のXDGデータ領域へ永続保存し、再生成に失敗しても既存音声を保持します。

- **動画出力（Phase 3）**：透明画像の合成、動画内音声を含むミックス、MP4/WebM、進捗表示・キャンセルに対応しています。プレビューと書き出しは共通の合成ルールを使い、既存の出力ファイルは上書きしません。

- **連続プレビュー（Phase 4）**：音声同期、再生・一時停止・停止・シーク、フレームスキップを実装しています。初回や編集後は、低解像度のプロキシを生成してから再生します。

- **字幕・効果・持ち出し（Phase 5）**：字幕・テキスト、位置・拡大率・不透明度、フェード・トランジション、音声波形に対応しています。VOICEVOX音声と自動字幕は一つのクリップとして扱い、アセット付きプロジェクトの書き出しもできます。

## 最近の改善

- **クリップの端ドラッグ**：選択したクリップの左右端をドラッグし、長さやトリミング範囲を変更できます。隣のクリップ・素材範囲・最短1フレームを守り、Escapeで取り消し、確定した一操作をUndoで戻せます。立ち絵・画像のGUI操作と、動画・音声・テキストの範囲制限を検証しました。

- **音声に連動する口の開閉**：同キャラクターのVOICEVOX音声を解析し、有音中は開いた口を保持、無音中は閉じる方式に変更しました。しきい値と開閉の待ち時間を調整でき、解析はバックグラウンドで実行してXDGキャッシュを再利用します。旧設定の読み込み、移動・トリミング・ミュート・シークと実FFmpegでの一致を検証しました。

- **口・目の未設定時の表示**：通常時のレイヤーやコマが未選択でも顔のパーツが消えないようにしました。元の基本表示へ戻し、古いプレビューキャッシュを更新します。指定PSDによる回帰テストと書き出し比較が成功しています。

- **実PSDでの口パク・目パチ**：グループ内の非表示差分が全部表示される問題と、初期状態の口・目が残る問題を修正しました。`*` 付き差分を切り替え、白目などの付随部品を復元し、サムネイルの縦横比も維持します。リポジトリ外のPSDによる描画・アニメーション・実FFmpeg比較が成功しています。

- **立ち絵レイヤーの選択**：口・目のレイヤー一覧にサムネイルを追加し、透明部分とグループの合成内容を確認できるようにしました。表示範囲だけを非同期で生成し、選択の保持・画像クリック・キャッシュ再利用・PSD切り替えの自動テストが成功しています。

- **PSD立ち絵**：独立した立ち絵設定、音声の有音・無音による口の開閉・可変コマの目パチ、同じキャラクターの音声との連動、プレビュー・プロキシ・出力を追加しました。設定はXDGの `sprites.json` で共有し、プロジェクトには設定IDと配置だけを保存します。操作と対応範囲は[立ち絵の実装・制限](SPRITES.md)を参照してください。

- **キャラクター名の入力**：IME変換中と一時的な空欄では保存を保留し、入力欄のIDを固定しました。変換確定のEnter・全消去・保存エラー表示でもフォーカスを維持するGUIテストが成功しています。

- **キャラクターと個別設定**：全プロジェクト共通のキャラクター管理と、クリップ単位の疎な上書きを追加しました。XDG設定への安全な保存、競合・破損保護、ピクセル座標の字幕、旧形式の読み込みに対応し、詳細は[実装記録](CHARACTERS.md)にまとめています。

- **フォント選択**：字幕・テキストに検索可能なフォント一覧を追加し、マウス・↑↓・Enterで選べるようにしました。検索中は設定を変更せず、IME変換中のEnterによる誤選択を防ぎ、従来のファイル指定も残しています。

- **大量クリップの書き出し**：長いフィルターグラフを一時ファイルから渡し、起動引数の上限による失敗を防ぎます。1,000クリップの起動と、実FFmpegによる大きなグラフのMP4出力を検証しました。

- **設定の保護**：音声保存先は編集用の値として保持し、検証に通った場合だけ適用します。終了時に拒否した値が保存されないようにし、以前の無効な設定も読み込み時に初期値へ戻します。

- **外部処理の終了**：アプリが起動したプロセス群を終了し、パイプ読み取りも中断できるようにしました。ラッパー経由の実行でも、タイムアウト・キャンセル時に子孫プロセスの出力待ちが残らないことを検証しています。

- **保存後の続行**：保存確認の「保存」が成功すると、保留していた閉じる・開く操作を続行します。初回保存でも動作し、保存失敗時は編集中の内容と確認画面を保持します。

- **素材パスの検証**：UTF-8として扱えない素材・フォントのパスは、取り込み・プロジェクト検証で明確に拒否します。保存やプレビューの段階でJSON変換に失敗する状態を防ぎます。

- **プロジェクト検証**：クリップを開始時刻で並べて隣接範囲を比較し、全クリップ同士の二乗時間の検査をなくしました。素材の参照確認にもID索引を使い、10,000クリップの検証と不正な境界の拒否をテストしています。

- **Undoの容量・操作単位**：履歴を差分保存にし、最大50件・差分の概算64MiBで制限します。プロパティの連続操作は1回のUndoにまとめ、レイヤー・素材・クリップの変更のUndo/Redoも検証しています。
