# VoxMovieMaker 開発・検証状況

最終動作検証日は2026-11-02です。Phase 0〜5の主要機能を実装した開発版で、配布前の最終確認は完了していません。

## 実装済み機能

- **画面・設定（Phase 0）**：Rust製GUI、Wayland/X11、日本語・英語・簡体字中国語、テーマ切替に対応しています。右側にプロパティ、最下部にVOICEVOX入力欄を配置しています。

- **タイムライン編集（Phase 1）**：素材の直接ドロップ、移動・分割・数値トリミング・削除・コピー、Undo/Redo、レイヤーの並べ替えに対応しています。すべて汎用レイヤーで、下段ほど映像の前面になります。

- **VOICEVOX（Phase 2）**：話者・スタイル選択、音声生成・試聴・再生成を実装しています。生成WAVはGit管理外のXDGデータ領域へ永続保存し、再生成に失敗しても既存音声を保持します。

- **動画出力（Phase 3）**：透明画像の合成、動画内音声を含むミックス、MP4/WebM、進捗表示・キャンセルに対応しています。プレビューと書き出しは共通の合成ルールを使い、既存の出力ファイルは上書きしません。

- **連続プレビュー（Phase 4）**：音声同期、再生・一時停止・停止・シーク、フレームスキップを実装しています。初回や編集後は、低解像度のプロキシを生成してから再生します。

- **字幕・効果・持ち出し（Phase 5）**：字幕・テキスト、位置・拡大率・不透明度、フェード・トランジション、音声波形に対応しています。VOICEVOX音声と自動字幕は一つのクリップとして扱い、アセット付きプロジェクトの書き出しもできます。

## 最近の改善

- **大量クリップの書き出し**：長いフィルターグラフを一時ファイルから渡し、起動引数の上限による失敗を防ぎます。1,000クリップの起動と、実FFmpegによる大きなグラフのMP4出力を検証しました。

- **設定の保護**：音声保存先は編集用の値として保持し、検証に通った場合だけ適用します。終了時に拒否した値が保存されないようにし、以前の無効な設定も読み込み時に初期値へ戻します。

- **外部処理の終了**：アプリが起動したプロセス群を終了し、パイプ読み取りも中断できるようにしました。ラッパー経由の実行でも、タイムアウト・キャンセル時に子孫プロセスの出力待ちが残らないことを検証しています。

- **保存後の続行**：保存確認の「保存」が成功すると、保留していた閉じる・開く操作を続行します。初回保存でも動作し、保存失敗時は編集中の内容と確認画面を保持します。

- **素材パスの検証**：UTF-8として扱えない素材・フォントのパスは、取り込み・プロジェクト検証で明確に拒否します。保存やプレビューの段階でJSON変換に失敗する状態を防ぎます。

- **プロジェクト検証**：クリップを開始時刻で並べて隣接範囲を比較し、全クリップ同士の二乗時間の検査をなくしました。素材の参照確認にもID索引を使い、10,000クリップの検証と不正な境界の拒否をテストしています。

- **Undoの容量・操作単位**：履歴を差分保存にし、最大50件・差分の概算64MiBで制限します。プロパティの連続操作は1回のUndoにまとめ、レイヤー・素材・クリップの変更のUndo/Redoも検証しています。

## 未実装・未確認

- **操作の最終確認**：実ファイルマネージャーからのドロップ、OS保存ダイアログ、日本語IME、Systemテーマ追従などの手動確認が残っています。複数モニター・DPI・音声デバイスごとの動作や、人による音声と映像の同期評価も必要です。
